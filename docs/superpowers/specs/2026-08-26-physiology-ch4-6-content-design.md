# 生理学第 4–6 章高频考点补全设计

**日期：** 2026-08-26  
**范围：** `src/data/physiol.ts` 的第四章至第六章；不改动应用逻辑、类型定义或构建配置。

## 目标

为医学应试复习系统补入第 4–6 章的高频知识点。每个知识点遵循既有 25 维度模型，内容采用简洁、考点导向的中文表述，覆盖执业医师考试和西医综合的核心机制、比较点与临床联系。

## 知识点范围

### 第四章 血液循环

1. 心肌细胞的生物电活动与兴奋性
2. 心肌兴奋-收缩耦联与心肌收缩特性
3. 心动周期与心音
4. 心输出量及其调节
5. 动脉血压及其调节
6. 微循环与组织液生成
7. 静脉回流与中心静脉压
8. 心血管活动的神经-体液调节

### 第五章 呼吸

1. 肺通气原理与呼吸运动
2. 肺容积、肺容量与肺通气量
3. 肺泡通气与肺换气
4. 氧的运输与氧解离曲线
5. 二氧化碳的运输
6. 呼吸运动的调节
7. 缺氧的类型与生理影响

### 第六章 消化和吸收

1. 消化道平滑肌生理与胃肠神经体液调节
2. 唾液分泌与吞咽
3. 胃液分泌与胃排空
4. 胰液与胆汁分泌
5. 小肠液分泌与小肠运动
6. 糖、脂肪和蛋白质的吸收
7. 胃肠激素的作用

## 数据约束

- 章节 ID 保持 `p4`、`p5`、`p6`；知识点 ID 使用 `ph4-*`、`ph5-*`、`ph6-*`。
- 每个 `dims` 对象包含现有 25 个维度键；`c4_lastreview` 与 `c4_nextreview` 保持空字符串。
- 不新增长度模型、维度键或运行时功能。
- 内容不替代临床诊断或治疗建议，仅用于医学考试复习。

## 验证

1. `npm run typecheck` 通过。
2. `npm run build` 通过。
3. 静态检查第 4–6 章的知识点数量和每点 25 个维度键。
4. 打开构建产物，确认侧栏可切换第 4–6 章的每个知识点。
