# 医学应试复习系统（生化 / 生理 / 病理 / 内科 / 外科）

一个**纯静态、零构建**的多科目交互复习网页，按你给定的 **25 维度 × 5 章** 模型组织，面向执业医师 / 研究生考试。

- 科目随时切换：生物化学、生理学、病理学、内科学、外科学
- 章节贴合标准学习大纲（章节大纲已按各科 syllabus 预置）
- 每个知识点用 25 个维度拆解：认知 / 应用 / 错误辨析 / 知识网络 / 薄弱环节
- 三种模式：**浏览**（看全部 25 维度）、**复习**（卡片+间隔重复）、**编辑**（电脑端增删改）
- 手机端自动隐藏「编辑」，仅做复习交互；电脑端负责主要编辑
- 数据存于 `data/*.js`，可直接双击打开，也可部署到 GitHub Pages

---

## 一、本地打开

### 方式 A：直接双击（最简单）
双击 `index.html` 即可在浏览器打开。
> 注意：部分浏览器在 `file://` 下会禁用 `localStorage`（复习进度/编辑可能不持久）。如需稳定保存进度，用方式 B。

### 方式 B：本地小服务器（推荐，进度可持久化）
在项目目录执行（任选其一）：
```bash
python3 -m http.server 8080
# 或
npx serve .
```
然后浏览器访问 `http://localhost:8080`。

## 二、部署到 GitHub Pages（手机随时复习）

1. 在 GitHub 新建仓库（如 `med-review`）。
2. 把本目录全部内容（`index.html`、`assets/`、`data/`）推送到仓库：
   ```bash
   git add -A && git commit -m "init med review" && git push
   ```
3. 仓库 **Settings → Pages → Source** 选择分支（如 `main`）与根目录 `/ (root)`，保存。
4. 几分钟后访问 `https://<用户名>.github.io/<仓库名>/`。
5. 手机用同一浏览器打开该网址即可复习；复习进度按浏览器本地保存。

> 小提示：GitHub Pages 是静态托管，不跨设备同步进度。要换设备延续进度，可在电脑端「编辑 → 导出本学科 JSON」备份，再在另一设备导入（或直接在 `data/` 提交更新）。

## 三、电脑编辑 / 手机复习 分工

| 端 | 能做的 | 不能做的 |
|---|---|---|
| 电脑（浏览器） | 浏览、复习、**编辑（增删章节/知识点、填 25 维度）、导出 JSON** | — |
| 手机（浏览器） | 浏览、复习（卡片+评分+间隔重复） | 编辑（已隐藏，防误触） |

**编辑操作（电脑端，点「编辑」标签）：**
- 在左侧目录选知识点 → 在右侧表单填写 25 个维度 →「保存（本地）」。
- 「+ 知识点」「+ 章节」「删除本点」用于扩展大纲。
- 「导出本学科 JSON」：下载 `biochem.js` 等文件，覆盖 `data/` 下对应文件后提交，即可在所有设备生效。

**复习操作（手机/电脑，点「复习」标签）：**
- 卡片正面只显示知识点标题与「凭记忆回忆」提示，点「显示答案」看全部维度。
- 根据回忆程度点 **忘记 / 模糊 / 记住 / 熟练**，系统按间隔重复（Spaced Repetition）自动排定下次复习时间，并标记薄弱点。
- 顶部「待复习 / 薄弱 / 全部」可切换复习范围；侧栏与顶栏徽章显示待复习、薄弱数量。

## 四、25 维度模型

| 章 | 维度 | 说明 |
|---|---|---|
| 第一章 知识认知 | ①核心概念 ②关键词 ③核心原理 ④核心结构 ⑤关键变量 ⑥核心结论 | 是什么/为什么/靠什么 |
| 第二章 知识应用 | ⑦使用条件 ⑧典型应用 ⑨典型题型 ⑩变式问题 ⑪边界与局限 | 何时用/怎么考 |
| 第三章 错误与辨析 | ⑫易错点 ⑬易混淆 ⑭错误类型 | 易错/易混 |
| 第四章 知识网络与记忆 | ⑮知识关联 ⑯记忆钩子 ⑰遗忘状态 ⑱最近复习 ⑲下次复习 | 关联/钩子/复习调度 |
| 第五章 薄弱环节与长尾 | ⑳掌握程度 ㉑薄弱程度 ㉒薄弱来源 ㉓错误频率 ㉔影响程度 ㉕修复优先级 | 掌握/薄弱/优先级 |

⑰–⑲ 与 ⑳–㉕ 为**复习状态维度**，由复习评分自动维护（也可在编辑模式手动填写）。

## 五、目录结构

```
med-review/
├── index.html          # 应用入口
├── assets/
│   ├── styles.css      # 样式（含手机响应式）
│   └── app.js          # 全部逻辑（科目切换/25维度/复习调度/编辑导出）
└── data/
    ├── biochem.js      # 生物化学（第1-2章已用25维度完整填充，其余为大纲）
    ├── physiol.js      # 生理学（大纲+种子点）
    ├── patho.js        # 病理学（大纲+种子点）
    ├── internal.js     # 内科学（大纲+种子点）
    └── surgery.js      # 外科学（大纲+种子点）
```

## 六、扩展内容

当前生化第 1–2 章已用 25 维度较完整填充，其余章节与科目为大纲占位 + 少量种子点。
在电脑端「编辑」模式逐章补全即可；也可直接编辑 `data/*.js` 文件（结构见上表维度键）。
所有内容均为纯文本，易备份、易用 Git 管理版本。
